# SunamoWf.Controls

## Short description

Sada vlastních WinForms ovládacích prvků (textboxy s validací, barevné tlačítko, základ DataGridView, ComboBox pro enum, PictureBox s výběrem, rozšířený RichTextBox, ToolStrip prvky s kalendářem). Vznikla migrací části `sunamo.wf`; migrace je záměrně neúplná.
Balíček je self-contained: nereferencuje jiné Sunamo balíčky (závislost na SunamoExceptions byla odstraněna).
